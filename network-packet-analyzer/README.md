# Network Packet Analyzer
- Here we are capturing the packets of the network protocols(tcp/udp/icmp) travelling through various network interfaces(eth0/lo)

## Features
- List network interfaces
- Let the user select an interface
- Capture packets
- Capture only TCP
- Capture only UDP
- Capture only ICMP
- Filter by IP
- Filter by port
- Save captures to .pcap
- Read previously saved captures
- Produce a small traffic summary
