# Linux Vulnerability Assessment & Risk Reporter
- Here we are building a Bash tool that performs a vulnerability-oriented assessment of yout Kali/Linux lab.

## Features
- Detect OS and Kernel Version
- List installed packages and versions
- Check for available security updates
- Identify outdated packages
- Check risky running services
- Check listening ports
- Check firewall status
- Check important file permissions
- Assign severity LOW, MEDIUM, HIGH or CRITICAL
- Save findings to a report
- Track whether findings are OPEN or REMEDIATED
