# Linux Incident Response Investigation Console
- A Bash-based incident response tool that investigates suspicious activity, correlates security events into a timeline and documents findings from detection through recovery.


## Features
- System Information
- Logged-In Users
- Failed SSH Logins
- Running Processes
- Listening Ports
- Active Connections
- Recently Modified Files
- Search IOC
- Build Incident Timeline
- Record Investigation Note
- Generate Incident Report
