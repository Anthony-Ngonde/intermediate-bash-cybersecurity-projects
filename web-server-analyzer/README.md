# Web Server Log Threat Analyzer
- Here we are analyzing access logs and identifying potentially suspicious web requests

## Features
- Most active IPs
- 404 errors
- 403 errors
- Repeated requests
- Suspicious request patterns
- Requests to sensitive paths
- Unusual user agents

## Run
git clone https://github.com/Anthony-Ngonde/intermediate-bash-cybersecurity-projects.git,
cd intermediate-bash-cybersecurity-projects/soc-dashboard,
chmod +x project.sh,
./project.sh
