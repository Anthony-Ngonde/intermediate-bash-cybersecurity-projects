# Automated Security Audit Tool
- This is a script that performs a complete security check on your Kali/Linux Machine

## Features
- Current User/root status
- OS/kernel information
- Disk Usage
- Running services
- Listening ports
- Active connections
- Firewall Status
- Failed SSH attempts
- Users with login shells
- File permissions on selected sensitive files
- Suspicious processes
- Recent system log errors
